# 数据库脚本使用说明

项目不使用 Flyway 等自动数据库迁移工具，服务启动时不会自动创建或修改表。

## 全新数据库

1. 创建并选中 `momentliving` 数据库。
2. 执行 `01-init-schema.sql`。
3. 再启动 Java 服务。

`01-init-schema.sql` 包含 `DROP TABLE IF EXISTS`，只能用于全新环境或确认可以重建的数据库，不能直接用于已有业务库。

## 已有数据库升级

秒杀可靠性整改涉及 `purchase_slot`、唯一约束和查询索引。旧数据库只需手工执行一次 `02-seckill-reliability-upgrade.sql`。

执行前必须备份数据库，并先检查目标列和索引是否已经存在。当前开发库已经完成过这次升级，不要重复执行。

## 如何在 IDEA 中执行

1. 打开右侧 **Database**，连接 MySQL。
2. 选中 `momentliving` 数据库，打开对应 SQL 文件。
3. 全新库执行 `01-init-schema.sql`；旧库只执行尚未执行过的升级脚本。
4. 点击运行后检查控制台没有红色错误，再启动服务。

以后修改表结构时，在此目录新增带日期或序号的普通 SQL 文件，并在提交说明中记录执行顺序即可。
